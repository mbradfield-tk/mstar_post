# M-Star Post (mstar_post)
Web UI for post-processing M-Star CFD results. FastAPI backend (backend/app), React+Vite+TS frontend (frontend/src), Three.js 3D, Plotly plots.

- Backend modules: config.py (env: MSTAR_POST_ROOTS=/data:/data2, MSTAR_POST_DATA=/data/mstar/mstar_post_data), paths.py (path guards; all client paths must stay inside ROOTS), cases.py (discovery/inventory; wraps ../mstar_stats_summary/mstar_stats_summary.py), vtkio.py (memmapped .vti planes, isosurfaces, STL export with disk cache), jobs.py (SQLite queue, subprocess per job, WebSocket status; job status: failed when a step without continue_on_error fails or every step fails; per-case jobs (continue_on_error steps) are done while at least one case succeeded, whichever case failed, with error "N of M step(s) failed" and returncode = the last failing step's code; a job still running when the backend stops is recorded failed "interrupted by a backend restart" (CancelledError branch of _run), never done; delete = remove row + run dir, rerun = wipe run dir and queue the stored commands again with the same job id (the run folder is removed in a thread, asyncio.to_thread(_clear_run_dir), so a large folder does not stall the event loop; JobManager._clearing refuses a second delete/re-run of the same job meanwhile with 409), both refused while queued/running; run dirs must be inside PROJECTS_DIR; job labels are unique per project: default tasks.default_label = task + switched-on bool options + case count, duplicates get " #2", ...; optional name on the Run tab; rename = PATCH /api/jobs/{id} (Jobs tab Rename, 409 if taken, also updates job.json); every job records `user` = the logged-in account (auth.current_user; see Identity), cleaned by jobs.clean_user, fallback = server account (getpass); rerun re-attributes to the re-running user; stored in the jobs table (ALTER TABLE on old DBs), job.json and the runs listing; shown on Jobs cards/detail, Results run list and the run overview), tasks.py (task registry with Task.group "base" | "addon": stats_summary (base: steady means, mixing, power metrics, settings, plots; no dispersion params any more), dispersion (add-on "Liquid-liquid dispersion": same script with --dispersion [--uniformity] --addons-only so only the *_dispersion/*_uniformity tables, per-case time series are written; Task.launcher = "stats_summary" so the root launcher's helper.conf entry is shared), calc_ua, cfd_zoner, custom_script; the Run tab lists Base and Add-ons and hints when the base summary is missing for the selected cases), routers/.

Once opened, a tab stays mounted (App Pane, display none when hidden; key = tab|project|reset count) so its state survives tab switches; every pane is wrapped in an ErrorBoundary (ErrorBoundary.tsx: a render error shows the message with "Reload this view" = remount, instead of blanking the app; also around the root in main.tsx and around the content of each Plots mode); window scroll is saved per tab and a resize event is fired on switch (Plotly); Viewer3D skips rendering/resizing while hidden; Results and Plots refresh their run lists when shown (active prop) and have Reset buttons (remount; Plots also clears mstar_post.plots/means.<pid>, keeps plot style and case names).
